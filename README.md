# 7881 自动报价 · 桌面控制台

参考截图用 PySide6 实现的自动报价控制台界面，包含运行控制、速度设置、话术管理与运行日志，并接入 7881 官方网页登录、回收报价大厅数据读取与账号估价。

> 自动报价流程仍为本地模拟；回收报价大厅数据来自 7881 网页，估价由外部估值接口计算。

## 运行

```bash
cd 7881_Quote
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## 目录结构

```text
main.py                    # 程序入口，只负责创建 QApplication 与主窗口
app/
  config.py                # 路径、默认配置、读写与数值归一化
  theme.py                 # 字体、样式表加载、应用图标
  engine.py                # 报价运行引擎（轮询、模拟报价、统计信号）
  hall.py                  # 7881 会话、登录 Cookie 与回收大厅抓取服务
  valuation.py             # 大厅文本解析与估值接口客户端
  resources/
    style.qss              # 全局样式
    hall_extract.js        # 回收报价大厅数据提取脚本
  ui/
    main_window.py         # 主窗口组装与模块接线
    widgets.py             # 通用控件与卡片布局
    run_panel.py           # 运行控制卡片
    speed_panel.py         # 速度设置卡片
    scripts_panel.py       # 话术管理卡片
    log_panel.py           # 运行日志面板
    dialogs.py             # 排除规则、7881 登录弹窗
```

新增功能时优先放到对应的 `panel` / 服务模块；`main.py` 保持为纯入口，不再承载业务代码。

## 7881 登录与估价

1. 点击右上角「登录 7881」，在应用内打开的 7881 官方登录页完成扫码 / 短信 / 密码登录（验证码在官方页面内完成）。
2. 登录后点击「估价」：读取回收报价大厅当前页，取前 10 条，从标题中解析流动资产、干员皮肤、近战武器、二次实名等信息，调用 `http://47.104.224.59/api/quote`，把每条返回价格打印到运行日志。
3. 登录 Cookie 保存在本机 `web_profile/` 目录（已被 `.gitignore` 忽略），应用不保存账号密码。

估值接口地址、`X-API-Key` 与 `platform` 配置在 [app/valuation.py](app/valuation.py)。

## 功能

- **开始 / 停止**：启动后按检测间隔轮询，按报价间隔生成报价记录。
- **统计面板**：已报价、已略过、追求、已排除、被同意实时累加。
- **速度设置**：报价倍数、报价间隔、检测间隔可调，运行中修改倍数即时生效。
- **话术**：可添加、编辑、删除多条话术，`保存配置` 写入 `config.json`，`还原` 撤销未保存修改。
- **排除规则**：弹窗维护关键字列表，命中后自动略过并计入“已排除”。
- **7881 登录**：右上角「登录 7881」打开内嵌官方登录页，支持扫码 / 短信 / 密码登录；Cookie 保存在本地 `web_profile/`，下次启动仍然有效。账号密码只在官方页面中输入，应用本身不保存。
- **估价**：登录后点击「估价」，读取回收报价大厅当前页的前 10 条，解析文本并调用估值接口，价格逐条打印到运行日志。
- **运行日志**：带时间戳的彩色日志，自动滚动，最多保留 1000 行；页面无滚动条。
