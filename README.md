# 7881 自动报价 · 桌面控制台

参考截图用 PySide6 实现的自动报价控制台界面，包含运行控制、速度设置、话术管理与运行日志。

> 当前报价数据为本地模拟，未接入真实接口；接入服务时可替换 `MainWindow._poll()` / `_quote()` 中的模拟逻辑。

## 运行

```bash
cd 7881_Quote
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## 功能

- **开始 / 停止**：启动后按检测间隔轮询，按报价间隔生成报价记录。
- **统计面板**：已报价、已略过、追求、已排除、被同意实时累加。
- **速度设置**：报价倍数、报价间隔、检测间隔可调，运行中修改倍数即时生效。
- **话术**：可添加、编辑、删除多条话术，`保存配置` 写入 `config.json`，`还原` 撤销未保存修改。
- **排除规则**：弹窗维护关键字列表，命中后自动略过并计入“已排除”。
- **运行日志**：带时间戳的彩色日志，自动滚动，最多保留 1000 行；页面无滚动条。
